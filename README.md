# Video Steganography with Multifactor Authentication

A deep learning-based project for securely hiding a video inside another video, combined with multifactor authentication.

## About the Project

This project focuses on secure video steganography using deep learning. A secret video is hidden inside a cover video and can later be recovered through the decoding process.

The system also includes password and audio-based authentication to provide an additional layer of security. A Django web application was developed to provide the interface for encryption and decryption.

## What I Worked On

- Worked on deep learning-based video encoding and decoding
- Implemented video steganography for hiding a secret video inside a cover video
- Worked with password-based authentication
- Worked with audio-based user verification
- Used OpenCV for video processing
- Developed the web application using Django
- Tested the system with video and audio inputs
